# 参考音频驱动配音

已确认方案、原声、准确原文和生成参数仍以[声音参考配置](../assets/audio-reference/reference-driven-v1/声音参考配置.json)为准；声音认可不代替本期台词与样片确认。纯开场和分隔音可复用；新正文须把真实参考 WAV、准确原文和新台词输入 Base 模型，不能用合成试听代替原声。

## Windows 10/11 x64 即装即用

Skill 与同仓库 Release 配套：独立 CPython 3.12、应用本地 C++ 运行库、已验证的 CPU 配音依赖及完整 Qwen3-TTS Base 模型。使用相对路径，不依赖原作者电脑、全局 Python、pip 或 CUDA。首次需取得几 GiB 运行附件，后续离线复用，不调用收费 API。建议内存 16 GiB 以上。

在实际安装目录执行（Codex 应自行定位 Skill 真实路径，不照抄旧机器路径）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\narrate.ps1 -Check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\narrate.ps1 -TextFile 'D:\当期项目\已确认台词.txt' -Output 'D:\当期项目\配音_v1.wav'
```

入口缺失运行包时自动调用安装器，从固定版本 Release 下载并核对分卷和整包 SHA256，使用暂存目录完整检查后提交新版本目录。后续直接使用 `.runtime/<版本>/python/python.exe`。首次不方便联网时加 `-BundleDirectory 'E:\运行分卷目录'`，或直接复制整个已安装 Skill，包含 `.runtime/`；无需重复安装依赖或下载模型。

入口参数与错误见[narrate 操作手册](narrate.md)。只检测不下载用 `install-runtime.ps1 -CheckOnly`，安装预览用 `-DryRun`。详细离线安装、空间需求、校验与恢复见[安装手册](install-runtime.md)，回退见[移除手册](remove-runtime.md)。

## 版本与边界

[Release 清单](portable-runtime.json)固定完整运行包摘要；[模型清单](qwen-base-tts-manifest.json)保留原始仓库、revision 和各权重摘要；[依赖版本](qwen-runtime-freeze.txt)与[模型许可](../assets/licenses/Qwen3-TTS-APACHE2.txt)继续保留。模型清单中历史 `work/...` 路径仅作来源记录，实际模型按声音配置的相对路径查找。运行包逐文件 SHA256 清单和第三方许可证随附件保存。

安装不删除或修改旧项目环境。原项目仍可按原绑定复用；跨机方案使用独立安装副本。`.runtime/` 属基础设施，不随测试清理，也不进入普通 Git 提交。运行包仅负责配音，浏览器、视频合成工具由具体制作方案选择；不包含历史资讯、渲染脚本、审核包或成片，不承诺 macOS/Linux/ARM64 可用。
