# 参考音频驱动配音

## 文件与当前机器绑定

- 参数、模型固定版本及用户确认记录：[声音参考配置](../assets/audio-reference/reference-driven-v1/声音参考配置.json)。
- 实际模型输入：[参考音频.wav](../assets/audio-reference/reference-driven-v1/参考音频.wav)＋[参考原文.txt](../assets/audio-reference/reference-driven-v1/参考原文.txt)＋本期已确认台词。
- [固定开场白](../assets/audio-reference/reference-driven-v1/固定开场白.wav)与[分隔音](../assets/audio-reference/reference-driven-v1/分隔音.wav)可直接复用；[试听实例](../assets/audio-reference/reference-driven-v1/口播声音实例.mp3)只供对齐声音，不能代替真实参考输入。
- 环境入口和模型目录在声音配置 `runtime` 中，是本机已有的外部基础设施；保留原路径。本 Skill 自身包含参考音频、配置、许可、依赖版本和模型来源清单，不包含 Python 环境及数 GB 模型权重。
- [依赖记录](qwen-runtime-freeze.txt)、[模型来源与摘要](qwen-base-tts-manifest.json)、[模型许可](../assets/licenses/Qwen3-TTS-APACHE2.txt)。模型清单中的 `work/...` 路径相对原运行项目，并非 Skill 内置文件；用 `runtime.model_directory` 定位实际模型。

## 检查与生成

从声音配置取 `runtime.python_executable` 作为 Python 入口，使用完整路径执行 [scripts/narrate.py](../scripts/narrate.py)。脚本在哪个工作目录运行均可，相对资源按 Skill 根目录解析。

PowerShell 示例（先将 `$skillDir` 设为实际安装目录）：

```powershell
$skillDir = Join-Path $env:USERPROFILE '.codex/skills/ai-daily-video'
$voiceConfig = Get-Content -LiteralPath (Join-Path $skillDir 'assets/audio-reference/reference-driven-v1/声音参考配置.json') -Raw -Encoding UTF8 | ConvertFrom-Json
$voicePython = $voiceConfig.runtime.python_executable
& $voicePython -B (Join-Path $skillDir 'scripts/narrate.py') --check
# 将以下两个路径替换为当期已确认台词和当期输出路径。
& $voicePython -B (Join-Path $skillDir 'scripts/narrate.py') --text-file 'D:/当期项目/已确认台词.txt' --output 'D:/当期项目/配音.wav'
```

- `--check` 核对参考摘要、运行文件和依赖可见性，不加载大模型、不生成音频、不联网。
- 生成使用 CPU、float32、eager attention、本地离线模型、完整 ICL，沿用配置中的 seed 和 temperature。按句意分段，以稳定自然的韵律衔接；按需要在同一进程内复用参考特征，避免每句重载模型。
- 台词 UTF-8 文件中空行分隔的段落分别生成，段间保留约 0.5 秒；同一资讯连续讲述不要无意义地拆段。生成后结合镜头检查实际停顿与节奏。
- 输出使用新 WAV 路径，已有输出会报错；用新版本文件名重试即可，不覆盖已确认音频。结果写入当前项目或指定目录，不写回 Skill。
- 本辅助入口输出模型原生 WAV，不自动改语速、音高或音色；按配置只允许必要的边界静音和响度处理。以试听核对轻柔自然程度，技术检查不代表已通过听审。

## 环境迁移与故障

先检查配置所指 Python 和模型目录；已有可用环境直接复用。运行环境含绝对路径，不将虚拟环境复制或移动进 Skill。迁移后可修改声音配置中的运行绑定，或用 `--config` 指向包含完整声音参数的新配置；`files.path` 的相对路径仍按 Skill 根目录解析。

只有缺失、损坏或必要升级时才按记录准备环境。恢复模型时按清单中的仓库、revision 和摘要核对；依赖记录是已验证版本的恢复依据，选择对应平台兼容的 CPU 安装包，不盲目跨平台照装全部锁定依赖。仅使用免费公开下载和本地推理，不开付费 API，不复制旧测试脚本、缓存或成片来充当运行必需文件。

脚本正常失败只留下本次尚未完成的新输出；检查后可删除该新文件并以新文件名重试，参考原声、配置和原模型不受影响。安装本 Skill 不会删除或改写原项目；清理测试时保护 `runtime` 指向的环境与模型。
