# AI日报 B站投稿填写模板

本模板参照“刚睡醒的bot”的 B 站 AI 日报草稿整理，适用于之后各期。每期依据实际成片、封面、章节表和来源资料填写；不要把示例、占位符或上一期的事实直接用于新一期。

## 使用方式

1. 复制本模板到当期目录或 `投稿记录/日期/`，命名为 `AI日报_日期_B站投稿信息.md`，并完成所有适用项。
2. 以成片的实际内容、时间轴及来源为准填写标题、标签和简介；条目数量随当期内容增减。
3. 本 Skill 在用户确认完整视频后填写本地文档，供用户手动投稿；不因模板含平台核对项而上传视频、保存平台草稿或提交投稿。用户另行明确要求平台操作时，按该次授权执行。
4. 下面的平台操作核对项供用户后续使用。尚未执行的操作保持未勾选，记录“未执行／待用户操作”；资料不全标记待确认，不把本地填写稿写成平台已保存的草稿。B 站界面和字段可能变化，具体投稿时以实际页面为准。

## 一、投稿填写单

| B站项目 | 本期填写内容 |
| --- | --- |
| 投稿账号 | 刚睡醒的bot（投稿前核对当前登录账号） |
| 日报日期 | 【YYYY-MM-DD】 |
| 视频文件 | 【本期成片的完整路径、时长、分辨率】 |
| 封面文件 | 【本期封面完整路径】 |
| 标题 | 【重点资讯1】，【重点资讯2】｜AI日报【MM.DD】 |
| 创作声明 | 【根据本期实际情况选择；含 AI 生成画面或配音时选择页面对应的“含AI生成内容”】 |
| 分区 | 【人工智能；如页面分区变化，选择最贴近本期内容的分区】 |
| 标签 | 人工智能、AI资讯、AI日报、【本期涉及的产品、模型或公司名称】 |
| 简介 | 填写下方“二、简介正文”中的完整内容 |
| 播放器章节 | 【已设置／未设置及原因；与简介时间目录分别记录】 |

标题写清最值得关注的变化，保留“计划、预计、传闻”等必要限定，符合 B 站当前字数限制。标签只写本期实际涉及的内容，不强行凑数量；此前草稿中的产品名称仅作示例。

标题格式示例（仅供理解，不能作为新一期事实）：

> ChatGPT与Codex 12月共享额度，苹果智能将接入千问｜AI日报11.01

## 二、简介正文

以下代码块的内容是要粘贴进 B 站“简介”的结构。替换所有【占位内容】，按本期实际条目增加或删除目录、来源行，删除这段说明后再投稿。

```text
【YYYY年M月D日】 AI日报：【用一句话概括本期最重要的产品、模型和行业动态】。

【本期目录】
【MM:SS】 【资讯1的简短标题】
【MM:SS】 【资讯2的简短标题】
【MM:SS】 【资讯3的简短标题】
【按实际条目继续添加】

【资讯来源】
【资讯1主体或主题】：【对应原始公告、论文、原帖或报道链接】
【资讯2主体或主题】：【对应来源链接】
【资讯3主体或主题】：【对应来源链接】
【按实际条目继续添加；转载报道注明报道方及原出处】

资讯整理截止北京时间【YYYY年M月D日 HH:MM】，具体情况请以原始来源及后续更新为准。
```

时间取自本期最终成片或章节表；来源与对应资讯逐项匹配。无法核实的链接、时间和事实标记为待确认，不编造；正式投稿前移除所有未解决的占位符。

## 三、封面与投稿核对

- [ ] 视频是本期最终成片；确认上传完成。记录视频播放或解码检查结果，不把技术检查写成人工听审已通过。
- [ ] 按页面要求检查 4:3 首页推荐封面和 16:9 个人空间封面；分别调整并预览。若裁切遮挡标题或重要资讯，记录问题并请用户确认或提供合适版本。
- [ ] 标题、分区、AI 声明、标签和简介与本期实际内容一致；来源链接和截止时间已核对。
- [ ] 简介目录时间与实际成片一致；播放器章节、独立字幕按页面能力和本期需要处理，不能把简介时间目录当成已配置播放器章节。
- [ ] 已保存草稿并重新打开，确认所填内容与两个封面版本实际保留；如平台未保存某项，记录并修正。
- [ ] 向用户说明实际草稿信息、封面裁切、尚未完成的章节或字幕、成片待听审问题；按当期授权取得提交确认。
- [ ] 获得提交授权后再操作“立即投稿”；在稿件管理中核对提交及审核状态。保存草稿、提交审核和审核通过分别记录，不混为一谈。
