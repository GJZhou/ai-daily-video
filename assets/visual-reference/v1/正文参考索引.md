# 正文参考：同一风格，多种组织方式

先查看[总览](正文参考总览.png)，再按当前素材与讲述关系选择相关示例；不必每期读取所有高清图或视频。

这些是可组合的呈现方向，不是固定模板或每期配额。上下与左右可以互换、重组；无需凑齐四类，也不限定素材比例、元素位置、节点数量或动画形式。所有案例均为历史内容，不作当期事实或历史播出清单。

| 示例 | 素材与讲述关系 | 参考重点 |
| --- | --- | --- |
| [上下布局](正文_上下布局.png) | 公告节选与时间安排 | 来源证据与编辑信息分层，上下成组、尺度协调。 |
| [左右布局](正文_左右布局.png) | 发布说明与中文要点 | 主素材与提炼内容就近对应；密集截图按需标出重点。 |
| [单素材主画面](正文_单素材主画面.png) | 评测图已经包含关键比较 | 让素材承担表达，不再堆叠重复卡片、数值或解释栏。 |
| [轻动画视频](正文_轻动画示例.mp4)／[关键帧分镜](正文_轻动画分镜.png) | 时间线随讲述切换焦点 | 主要构图和全部节点从开场可见，仅当前节点与关联线条轻柔强调。静态图不作为动效已展示的证明。 |

动画为6秒无声的局部效果演示，不是资讯篇幅或配音节奏标准。不能读取视频的模型可看分镜，由主模型检查实际播放与运动；不需每期重新转写或逐帧解析示例。

全组共用暖色浅底、近黑文字、克制橙色、接近的自制正文字号、可辨识的真实素材边界、固定字幕位置和全宽导航。案例未覆盖所有素材类型：产品演示、照片、海报或人物观点等按当期素材自主组织。简洁不等于静态翻页，多样也不等于频繁换模板或堆效果。
